01 / START WITH CONTEXT

A practical response to vague work

“Research this.”
“Build that.”
For whom? Why? Under what limits?

Most AI work begins with missing context. The audience, decision, evidence standard, constraints, deliverable, and definition of success are left for the Agent to infer.

This harness makes those choices visible. It is not an Agent runtime, a model benchmark, or a promise to make every model smarter. It is a reusable way to set a working environment before work begins.
