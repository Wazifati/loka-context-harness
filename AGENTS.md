# Loka Context Harness

Preserve the original Loka routing:

- ACE for vague/context work;
- V10 for planning/audit without repo tools;
- V11 for repository-capable build work;
- V12 Supervised or V12 Autonomous Edition only on top of V11;
- V13 for vibe-coding and visual builders, then V11 after export.

For repository-capable work, start with `loka-guard`. Use `loka-build` with
V11 after the task and existing project structure are understood.

Do not merge frameworks into a single default prompt. Use `agent-skills/loka-router`
to select the first applicable route. `reference-source/` contains the preserved
supplied originals; Agent Skills, Guard, Build, and the Autonomous Edition are
separate portable distribution material.
