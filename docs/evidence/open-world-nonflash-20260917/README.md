# Raw evidence — open-world, non-Flash comparison

This folder contains the exact two user prompts, two system conditions,
metadata, and 12 returned responses used by
[the comparison report](../../OPEN_WORLD_NONFLASH_COMPARISON.md).

- Scenarios are fictional, but deliberately realistic and geographically/audience specific.
- No source pack was supplied to any model.
- Each model received the same user prompt for a given scenario.
- The ACE condition uses the preserved [ACE Lite source](../../../meta-prompts/LOKA_ACE_LITE.md)
  plus a small comparison adapter that asks it to show the six-layer applied context.
- The request omitted a completion-token maximum; outputs are retained in full.
- No retries were made. All 12 calls completed.

These are illustrative outputs, not a benchmark, legal advice, financial advice,
or proof of universal improvement.
