# LokaV13

Use alone for vibe-coding and visual prompt-to-app environments such as Google
AI Studio Build, Antigravity IDE, Lovable, Bolt, v0, Replit Agent, and similar
builders. Choose the appropriate original mode: Initial Build, UI Patch,
Feature Add, Surgical Patch, Security Review, Rescue Mode, or Export Prep.

V13 governs the visual-builder environment: terminal permission policy,
browser-sub-agent verification limits, durable project memory, checkpointing,
and export preparation. A preview or visual check does not prove backend, auth,
payment, or data behavior.

When the project is exported to a standard repository/IDE with full control,
stop using V13 and switch to V11. Do not run V13 and V11 simultaneously for the
same active environment. The original full source is
`reference-source/9-LokaV13-Full-v13_2.pdf`.
