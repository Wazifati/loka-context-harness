# LokaV11

Use alone for repository-capable implementation, debugging, code changes, and
technical audits. It is the build operating system: it establishes runtime
readiness, durable state when appropriate, layer separation, read-before-write,
evidence-based completion, dependency verification, approval gates, and
surgical-fix discipline.

For a targeted change, use the original Surgical Fix Mode. For a long supervised
mission, load V12 Supervised on top of this skill. For the new autonomous mode,
load V12 Autonomous Edition on top of this skill. Do not load V10 or V13 with
V11 for the same active environment.

Use `loka-v11-lite` for the supplied one-page daily core. The original full
reference is `reference-source/2-LokaV11-Full-v11_3.pdf`.
