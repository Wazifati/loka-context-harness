# Loka Meta Prompts

Select one framework for the active environment. Every original environment has
a compact **Lite** alternative for direct copy-paste use; select either Full or
Lite, never both. Do not merge V10, V11, and V13 into one mega prompt.

| Situation | Full source | Lite prompt |
|---|---|---|
| Vague intent, research, strategy, content, workflow | Loka ACE | `LOKA_ACE_LITE.md` |
| App/prompt planning or audit without repo tools | Original V10 in `reference-source/5-LokaV10.pdf` | `LOKA_V10_LITE.md` |
| Repository-capable build work | Original V11 | `LOKA_V11_LITE.md` |
| Supervised 1–3 hour V11 session | Original V12 in `reference-source/8-LokaV12.pdf` | `LOKA_V12_LITE.md` |
| Bounded autonomous V11 mission | `LOKA_V12_AUTONOMOUS_EDITION.md` | `LOKA_V12_AUTONOMOUS_LITE.md` |
| Vibe coding or visual builders | Original V13 in `reference-source/9-LokaV13-Full-v13_2.pdf` | `LOKA_V13_LITE.md` |

V12 Supervised and V12 Autonomous are distinct editions. Both load only on V11
or V11 Lite; select either Full or Lite within the chosen V12 edition.
